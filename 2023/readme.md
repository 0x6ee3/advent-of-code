# Advent of Code 2023

After reading _Domain Modeling Made Functional: Tackle Software Complexity with Domain-Driven Design and F#_ this years solution will be solved with F#.

I will try to stay functional as much as possible, while also getting the job done. 

Some rules I will try to to keep in mind:

- don't use the mutable keyword at all
- don't use for loops or if-then-else, use pattern matching and recursion
- don't use "dot notation", but functions (eg. write String.length "hello" rather than "hello".Length)
- don't create classes, use F# types such as tuples, records and unions
- don't use the debugger, use REPL instead (I won't write unit tests tho)

These are taken from "Learning F#" section of F# for fun and profit: https://fsharpforfunandprofit.com/learning-fsharp/
